## 1. Introduction to Memory Management (5 minutes)

**Memory management** is an operating system function that manages the
computer's main memory (RAM). It keeps track of which parts of memory
are in use, allocates memory to processes when required, and releases it
when no longer needed.

### Why is it important?

-   Allows multiple programs to share RAM.
-   Allocates memory to processes efficiently.
-   Prevents one process from improperly accessing another process's
    memory.
-   Keeps track of free and occupied memory.
-   Helps improve system performance and memory utilization.

### Basic diagram

``` text
                 Operating System
                        |
          +-------------+-------------+
          |             |             |
       Process A     Process B     Process C
          |             |             |
          +-------------+-------------+
                        |
                  Main Memory (RAM)
          +--------------------------------+
          | OS | Process A | Process B | Free |
          +--------------------------------+
```

*Note:* This is a simplified illustration. The actual layout depends on
the operating system and memory-management method.

## 2. Need for Memory Management (10 minutes)

A computer has limited RAM, while several programs may need memory at
the same time. The OS must coordinate memory use safely and efficiently.

### Main objectives

1.  **Allocation:** Give memory to a process when it needs it.
2.  **Deallocation:** Release memory when a process finishes or no
    longer needs it.
3.  **Protection:** Prevent unauthorized access to another process's
    memory.
4.  **Sharing:** Allow processes to share selected code or data safely
    when required.
5.  **Relocation:** Allow a program to be placed or moved in memory
    while preserving correct address translation.
6.  **Efficient utilization:** Reduce wasted memory and use available
    RAM effectively.

### Example

Suppose RAM has 8 GB available. The operating system, a browser, and a
music player all need memory. Memory management decides how memory is
assigned and ensures that each process works within its permitted
address space.

### Exam point: Fragmentation

**Fragmentation** is memory waste caused by the way memory is allocated.

-   **Internal fragmentation:** Wasted space *inside* an allocated
    block.
-   **External fragmentation:** Free memory exists, but it is split into
    small non-contiguous holes.

``` text
Internal fragmentation
+-----------------------+
| Allocated block       |
| Process data | Waste  |
+-----------------------+

External fragmentation
+------+-----+------+-----+------+
| Used |Free | Used |Free | Used |
+------+-----+------+-----+------+
        Free space is split into holes
```

## 3. Logical Address vs Physical Address (10 minutes)

### Logical address

A **logical address** (also called a *virtual address*) is generated by
the CPU while a program is running. A program normally uses logical
addresses rather than directly referring to physical RAM locations.

### Physical address

A **physical address** is the actual location in main memory (RAM) where
the data or instruction is stored.

### Address translation

The **Memory Management Unit (MMU)** is hardware that translates logical
addresses into physical addresses.

``` text
          CPU
           |

     +-------------+

     +-------------+
```

### Simple example

Assume a simplified system uses this translation rule:

**Physical address = Logical address + Relocation value**

If the logical address is `120` and the relocation value is `1000`:

`Physical address = 120 + 1000 = 1120`

Therefore, logical address `120` maps to physical address `1120` in this
simplified example. Modern systems often use paging and more complex
translation mechanisms.

### Important distinction

Logical addresses and physical addresses may have the same numeric value
in some systems or configurations, but they represent different
concepts.

## 4. Basic Memory Allocation and Management (10 minutes)

Memory allocation means assigning portions of memory to processes.

### A. Contiguous allocation

Each process is placed in one continuous block of physical memory.

``` text
Main Memory
+--------------------+
| Operating System   |
+--------------------+
| Process A          |
+--------------------+
| Process B          |
+--------------------+
| Free space         |
+--------------------+
```

**Advantage:** Simple to understand and manage.\
**Limitation:** Can suffer from fragmentation and may be difficult to
fit a process into a suitable free block.

### B. Paging

Paging divides: - Logical memory into fixed-size **pages**. - Physical
memory into equal-size **frames**.

A page can be placed in any available frame. A page table records the
mapping from pages to frames.

``` text
Logical pages          Page table          Physical frames
+--------+             +----------+        +-----------+
| Page 0 | ----------> | 0 -> 2   | -----> | Frame 2   |
| Page 1 | ----------> | 1 -> 0   | -----> | Frame 0   |
| Page 2 | ----------> | 2 -> 3   | -----> | Frame 3   |
+--------+             +----------+        +-----------+
```

**Advantage:** Avoids external fragmentation in the allocation of
physical frames.\
**Limitation:** Can cause internal fragmentation, especially in the
final page, and requires page-table management.

### C. Segmentation

Segmentation divides a program into logical, variable-sized parts, such
as code, data, and stack.

``` text
Program
+------------------+
| Code segment     |
+------------------+
| Data segment     |
+------------------+
| Stack segment    |
+------------------+
```

**Advantage:** Matches the logical structure of a program and supports
segment-level protection/sharing.\
**Limitation:** Variable-sized segments can lead to external
fragmentation.

## 5. Quick Revision and Examination Questions (15 minutes)

### Key terms to remember

-   **Memory management:** OS function that tracks, allocates, protects,
    and releases memory.
-   **RAM:** Main memory used to hold currently running programs and
    data.
-   **MMU:** Hardware that translates logical addresses to physical
    addresses.
-   **Logical address:** Address generated by the CPU for a process.
-   **Physical address:** Actual location in RAM.
-   **Paging:** Memory-management method using fixed-size pages and
    frames.
-   **Segmentation:** Memory-management method using logical,
    variable-sized segments.
-   **Fragmentation:** Wasted memory caused by allocation patterns.

### Short-answer questions

1.  **What is memory management?**\
    It is the operating system function responsible for allocating,
    tracking, protecting, and releasing main memory.

2.  **State any four objectives of memory management.**\
    Allocation, deallocation, protection, and efficient memory
    utilization. Sharing and relocation are also objectives.

3.  **Differentiate between logical and physical addresses.**\
    A logical address is generated by the CPU and used by a process; a
    physical address identifies the actual location in RAM. The MMU
    translates between them.

4.  **What is the function of the MMU?**\
    It performs address translation and can enforce memory-access
    protection.

5.  **Differentiate between paging and segmentation.**\
    Paging uses fixed-size pages and frames; segmentation uses
    variable-sized logical units such as code, data, and stack.

6.  **What is fragmentation? Name its types.**\
    Fragmentation is wasted memory due to allocation. Its two common
    types are internal and external fragmentation.

### Multiple-choice practice

**1. Which hardware component commonly translates logical addresses into
physical addresses?**\
A. ALU\
B. MMU\
C. Compiler\
D. Control unit\
**Answer: B. MMU**

**2. Paging divides logical memory into:**\
A. Segments\
B. Variable-sized blocks\
C. Fixed-size pages\
D. Files\
**Answer: C. Fixed-size pages**

**3. External fragmentation means:**\
A. Waste inside an allocated block\
B. Free memory is split into separate holes\
C. The CPU is idle\
D. A process has ended\
**Answer: B. Free memory is split into separate holes**

### Last-minute revision

-   The OS manages RAM for multiple processes.
-   Memory management supports allocation, deallocation, protection,
    sharing, relocation, and efficient utilization.
-   CPU generates logical addresses; the MMU translates them to physical
    addresses.
-   Paging uses fixed-size pages and frames.
-   Segmentation uses variable-sized logical units.
-   Internal fragmentation is waste inside an allocated block; external
    fragmentation is scattered free space.
